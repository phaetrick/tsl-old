v1.9.1

  • Syncing to BPM.
  • Crash fixed when saving microphone recordings into file.

v1.9.0

  • Smaller grainsizes possible (1ms). Previously, the limit was 5ms.
  • Both grain envelopes, ENV1 and ENV2, are now applied to the grains.
  • New parameter: ENV PHASE.
  • New parameter: GLISS.
  • Optional higher-quality pitch manipulation of the grains.
  • New section: GRAIN GENERATION.
  • Grain Arpeggiator.
  • New cross-synthesis algorithm: LPC.
  • Tape Mode: Less computational overhead with enhanced sound quality.
  • Revised Envelope Followers.
  • Editing options for audio on track.
  • Recording directly to a track.
  • Saving and restoring of loop positions.
  • Upgrade: Save audio along with preset so that everything is in a single file.

v1.8.0

  • Bugfixes, numerical issues causing null sound at extreme settings seem to be resolved.
  • Smoother effect activation/deactivation.
  • For performance reasons some switches (like track/effect activation/deactivation) now only have an effect if the synth is powered on. This way the synth could be made completely lockless, reducing xruns.
  • Minor UI changes/improvements like smoother scrolling of lists.
  • New granulation parameter REVERSE. If set to 0.0 no reversed grains are generated, at 1.0 all grains are reversed, otherwise normal and reversed grains are generated randomly. If set to 0.5 the ratio of probability for normal and reversed grains is 1:1.
  • New phase vocoder algorithm SPECTRAL WARP, which maps one part of the spectrum to another part. Can be LFO modulated.
  • The LFOs now can have muliple targets, which can be activated/deactivated by clicking the new power button next to the LFO target selector.
  • New LFO target LOOP POS. Targets the whole loop.
  • Four slots for saving/restoring the state of the sequencer. On load the new state is queued until the current sequence finishes its last note.
  • Upgrade: MODAL as mono effect.
  • Upgrade: 3-band linear phase mono compressor.
  • Upgrade: Dynamic implementation of EQ5.
  • Upgrade: Saving/Restoring the whole project, all four tracks.
  • Upgrade: Limiter: Corrected release time.
